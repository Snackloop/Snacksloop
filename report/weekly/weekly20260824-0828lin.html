Q1什么零食让顾客每周回来？
执行方法
开业第一天即启用会员/手机号绑定消费记录；按单个SKU统计复购周期与复购率；开业首月建立基线，之后每周滚动对比，筛出"钩子商品"（顾客首单买了它、之后反复回来）。
需记录数据
  • 每笔交易：会员ID + SKU + 日期 + 金额
  • 每个SKU的 7日 / 14日 / 30日复购率
  • 复购顾客的首单SKU构成（识别引流钩子）
  • 复购顾客占比、复购顾客平均消费频次
建议负责人
小陈（数据）+ 小赵（零食选品侧解读）
开业前必须完成：会员系统上线并与POS打通。若开业首月没有会员识别，前一个月的复购数据将永久缺失，无法回溯。
Q2第三方盲盒到底占销售多少？
执行方法
在POS中为所有SKU预先打好品类标签（第三方盲盒 / BaoPop自有 / 零食 / 毛绒 / PVC / 日用 / 美妆等）；按周导出分品类销售构成。不只看销售额占比，同时看毛利占比和坪效——盲盒占用陈列面积大，只看销售额会高估它的价值。
需记录数据
  • 分品类：日/周销售额、销售额占比、毛利额占比
  • 分品类坪效（销售额 ÷ 该品类陈列面积）
  • 盲盒品类的动销率与周转天数
建议负责人
小陈（数据）+ 小林（陈列面积测算）
开业前必须完成：POS品类标签体系定稿 + 每个陈列位编号并登记面积。没有陈列面积数据就算不出坪效，而坪效才是决定"要不要扩大盲盒区"的真正依据。
Q3BaoPop 自己卖不卖得动？
执行方法
与第三方盲盒做同位置、同陈列条件的对照测试，并按周做位置轮换（A/B位互换）。不做轮换的话，一旦BaoPop卖得差，无法区分是"产品不行"还是"位置不好"，这个结论就白跑了。
需记录数据
  • BaoPop vs 第三方盲盒：单位陈列面积销售额
  • 动销率（有销售的SKU数 ÷ 总SKU数）
  • 复购率、退货率
  • 轮换前后各自的销售变化（分离位置影响）
建议负责人
小林（对照实验设计与位置轮换执行）+ 小陈（数据）
开业前必须完成：确定A/B对照位并编号、约定轮换周期。这是7项里最容易被做废的一项——如果开业后BaoPop随便找个角落摆，数据就没有任何解释力。
Q4毛绒是不是比 PVC 更强？
执行方法
必须按价格带分层比较。毛绒普遍单价高于PVC，直接比总销售额会得出错误结论。应在同价格带内（如 $10–20、$20–30）对比两者表现。
需记录数据
  • 分价格带的：动销率、周转天数、毛利率
  • 客单价贡献（含毛绒订单 vs 含PVC订单的平均金额）
  • 破损率 / 退货率（毛绒易脏污，这是隐性成本）
  • 陈列占用面积（毛绒占位大，需计入坪效）
建议负责人
小赵（选品）+ 小陈（数据）
开业前必须完成：入库时即录入价格带、材质（毛绒/PVC）、占位面积三个字段。可直接加进我已建的采购库系统作为标准字段，成本很低。
Q5雕像 / 拍照到底带来多少进店？
执行方法
门口安装客流计数器获取"进店人数"这一分母；雕像/拍照点做有/无 或 换位置的AB测试（例如某几日撤除或移位，对比进店人数变化）；拍照点设置扫码领券或专属话题标签，追踪社媒外溢。
需记录数据
  • 日进店人数、日成交单数 → 进店转化率
  • 雕像"有/无"两种状态下的进店人数差值
  • 拍照点扫码次数、带话题标签的社媒发帖数
  • 拍照点扫码顾客的后续成交率
建议负责人
小林（装置与AB测试设计）+ 小陈（数据）
开业前必须完成：客流计数器采购与安装。这是7项中唯一需要额外硬件的一项，也是最容易漏掉的一项。没有分母，这题永远算不出来，事后只能靠"感觉人变多了"，无法用于决策第二店要不要复制雕像。
Q6哪种商品组合把客单价做到 $20 / $25 / $30？
执行方法
从POS导出完整购物篮明细（每笔订单包含哪些SKU），做品类关联分析；按订单金额分档（<$15 / $15–20 / $20–25 / $25–30 / >$30），拆解各档的典型组合，找出"把客单价从$15推到$25的那个品类"。
需记录数据
  • 每笔订单的完整SKU组合与总金额
  • 订单金额分布直方图
  • 各金额档的品类组合频次（关联规则）
  • 加购率最高的搭配品类（用于设计组合陈列与套餐）
建议负责人
小陈（数据分析）+ 小林（据结论调整组合陈列）
开业前必须完成：确认POS支持导出订单级购物篮明细。部分POS只能导出SKU汇总销量、不能导出"哪些商品在同一笔订单里"，那样这题直接无解。这一条必须在POS选型时书面确认。
Q7619 成熟后，哪些模块可以原样复制到第二店？
执行方法
开业前先把 619 拆成可独立评估的模块：选品结构 / 陈列方案 / 引流装置 / 会员体系 / 供应链 / 人员配置 / 开业物料 / 视觉标准。每个模块预先定义"成功标准"（达到什么指标算跑通），开业后按月打分。
需记录数据
  • 每模块：投入成本、产出（销售/客流/毛利）
  • 可标准化程度（是否依赖特定人/特定供应商）
  • 对本地商圈的依赖度（换个商圈还成不成立）
  • 复制该模块所需的最低条件清单
建议负责人
小林（模块拆分与标准定义）+ 三人共同评分
开业前必须完成：模块划分与成功标准定稿。如果事后再拆模块，各模块的投入成本已经混在一起，无法归因，也就无法判断第二店该复制哪一块。
主动发现的关键风险
7 项里有 6 项的成败，取决于开业前的系统与硬件配置，而不是开业后的执行。汇总如下，建议全部插入 60 天倒排计划：
  1. 会员系统上线并与POS打通（Q1）
  2. POS品类标签体系定稿（Q2/Q3/Q4）
  3. POS支持订单级购物篮明细导出（Q6）— 必须书面确认
  4. 门口客流计数器采购安装（Q5）— 唯一需要额外硬件
  5. 陈列位编号 + 面积登记（Q2/Q3坪效计算）
  6. 模块划分与成功标准定稿（Q7）
我的判断与建议
  • 建议把第3项和第4项列为最高优先级。因为这两项一旦漏掉，事后完全无法补救（购物篮明细无法追溯、进店人数无法回填），而其余几项即使晚做，还能靠人工补录部分数据；
  • 建议这7项的周复盘从筹备期就开始，而不是等开业。筹备期复盘的内容是"前置条件完成到哪一步"，开业后才切换成"数据跑出什么结果"。这样能保证开业当天所有埋点都就位；
  • 关于老板提到的"人工选品 vs AI选品实际比较"：这本身就是一个设计良好的对照实验，建议把它正式纳入 Q7 的评估模块之一——如果比较结果显示某一种方式明显更优，这个方法论本身就是可以复制到第二店的资产。执行上建议用同一批候选商品、分别用两种方式各选出500 SKU，开业后对比两组的动销率与坪效。

我的判断与建议

主动发现的机会
盘货这件事可以一举三得，建议不要只当"清点存货"来做。盘货时如果同时录入以下字段，可以顺带完成三项前置工作：
  • 录入品类标签 + 材质（毛绒/PVC）+ 价格带 → 直接满足 Q2/Q3/Q4 的数据前置条件；
  • 录入陈列位编号 + 占位面积 → 满足 Q2/Q3 的坪效计算前置条件；
  • 盘出的现有货品可直接进采购库系统，与新供应商商品一起参与首批500 SKU 的筛选比价。
否则盘完货还要再返工录一遍标签，等于同样的活干两次。
我的判断与建议
  • 关于"人工选品 vs AI选品"的执行方式建议：两组必须用同一批候选商品池、同一套约束条件（预算、品类配比、SKU数），否则比较无效。选完后两份清单封存，开业后用动销率和坪效来判定，而不是开业前争论谁选得好；
  • 关于货架采购：建议先完成盘货再定货架方案。因为货架数量和规格取决于实际留用的商品量与品类结构，先买货架容易买错规格——我此前实测过 The Source 候选铺位的22类既有货架尺寸，那套测量方法可以直接复用到爱购店；
  • 关于优先级：老板明确"当前第一优先仍是按60天计划把619开出来"。本周参展占用了周一至周四，本项四件事（盘货/货架/选品/租赁条件整理）全部未启动，下周必须集中补上，否则会挤压60天主线。
